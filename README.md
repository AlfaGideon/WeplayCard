# WeplayCard — Помощник «Дуэль лжи»

Программа-помощник для карточной игры **«Дуэль лжи»** (вариант Холдема на 36 карт).
Она не играет *вместо* тебя — она считает математику за реальным столом и говорит,
**поднимать ставку или нет, в процентах** (шанс стать единственным победителем при вскрытии).

> Помощник **не использует случайные 15 000 итераций**. Он перебирает все
> допустимые будущие общие карты и закрытые пары соперников из 36-карточной
> колоды, затем точно считает все исходы вскрытия. Если на ранней стадии
> раскладов физически слишком много для браузера, приложение честно попросит
> открыть ещё общие карты, а не покажет случайный процент.

## Правила игры (как задано)

- **Колода:** 4 цвета (Синий, Красный, Жёлтый, Фиолетовый) × значения 1…9 = **36 карт**.
- **Раздача:** каждый игрок получает **2 карты в руки**; на стол выкладываются **5 общих**
  карт в три круга: 1-й круг — 3 карты, 2-й — 1, 3-й — 1 (все 5 могут открыться сразу).
- **За столом:** 2–4 игрока.
- **Комбинация** собирается из лучших 5 карт из 7 доступных (2 свои + 5 общих).

### Комбинации (ранг = уровень, чем выше — тем сильнее)

| Уровень | Название | Что это |
|---|---|---|
| 1 | Барашек | Старшая карта (нет комбинаций) |
| 2 | Кабан | Одна пара |
| 3 | Волк | Две пары |
| 4 | Буревестник | Три карты одного числа (сет) |
| 5 | Морал | Пять последовательных карт (стрит, любые цвета) |
| 6 | Носорог | Тройка + пара (фулл-хаус) |
| 7 | Медведь | Пять карт одного цвета (флеш) |
| 8 | Титан | Четыре одинаковые (каре) |
| 9 | Дракон | Пять последовательных одного цвета (стрит-флеш) |

> ⚠️ **Важное решение по ранжиру.** В ТЗ уровни пронумерованы 1→9, и мы следуем им как есть:
> **Медведь (флеш, 7) сильнее Носорога (фулл-хаус, 6)**. В классическом покере наоборот.
> Если хочешь стандартный порядок — поменяй местами ветки `isFlush` и фулл-хауса в `evaluate5()`
> (файл `engine.js`).

## Что считает помощник

1. **Текущая комбинация** — лучшая 5-ка из твоих карт + известных общих (нужно минимум 3 общих).
2. **Шанс победить** — вероятность стать единственным победителем в процентах. Банк не делится: если лучшая пятёрка и кикеры полностью равны, монстры выходят на случайную дуэль; среди N равных игроков каждому засчитывается шанс 1/N на единственную победу.
3. **Рекомендация** — Поднимать / Уравнивать / Пасовать, по порогам шанса победить:
   - ≥ 66% — 🔥 поднимай ставку
   - ≥ 50% — ✅ уравнивай (call)
   - ≥ 33% — ⚠️ малая ставка / рискованный блеф
   - < 33% — 🛑 пасуй
   - Если введёшь банк и ставку для колла — учтёт пот-оддсы.
4. **Панель решения по коллу** — после ввода «Банка» (до твоего колла) и «Колла» показывает:
   - минимальный шанс для безубыточного колла;
   - запас твоего точного шанса к этому порогу в процентных пунктах;
   - **EV колла** — ожидаемый результат именно этого решения, без уже вложенных фишек.
   Поля банка и колла обновляют эту панель мгновенно: точный перебор карт повторно не запускается.
5. **Распределение финальных комбинаций** — как часто ты заканчиваешь с каждым уровнем. Это отдельная величина: «Волк в финале 100%» означает только то, что твоя комбинация точно останется Волком, а не то, что она выиграет банк.

### Как выбрать количество игроков

В веб-интерфейсе переключатель показывает **общее число игроков за столом**: 2, 3 или 4.
Если вас было трое, выбери **3** — движок добавит тебя и **двух соперников**.
Это важно: против двух неизвестных рук шанс победить с Волком ниже, чем против одной. В Telegram-команде
последнее число по-прежнему означает именно число **соперников**.

### Точный перебор всех исходов

Поле **«Итераций» убрано**: процент всегда строится из полного пространства допустимых
раскладов, а не из случайной выборки. После первого круга (открыты 3 общие карты) движок
точно учитывает все будущие тёрн/ривер и руки **1–3 соперников** (то есть стол из 2–4 игроков).
Для четырёх игроков на флопе это, например, **19 879 587 000** реальных раскладов; движок
считает их комбинаторно по совместимым парам карт, без случайности.

До открытия достаточного числа общих карт полное пространство может содержать десятки
миллиардов или триллионы раздач. В таком случае программа не подменяет ответ Монте-Карло:
она покажет количество раскладов и попросит открыть ещё карту стола. Так в интерфейсе нет
ложной точности.

Пример готового стола: у тебя **Ф8, К4**, на столе **С4, С7, С8, К3, Ф2**, всего 3 игрока.
Точный результат: шанс победить **70,84%**, комбинация соперника сильнее в **28,33%**
раскладов, равная комбинация встречается в **1,65%** (тогда одного победителя выбирает удача).
Пара `5+6` у одного из двух соперников, которая даёт Морал `4-5-6-7-8`, входит в расчёт,
но встречается только в **7,78%** всех раскладов; именно возможность такой пары не делает
её вероятностью 100%. Если открыты только первые три карты **С4, С7, С8** (флоп), а не
ещё **К3, Ф2**, для тех же Ф8/К4 против двух соперников точный шанс уже **46,06%**.

> Математика не видит блеф и не читает оппонента — это честный шанс при вскрытии.
> Побеждает только один: равная комбинация не делит банк, а отправляет равных монстров
> на случайную дуэль. Поэтому, например, 71% не исключает один конкретный проигрыш:
> остальные исходы всё ещё могут привести к Моралу у соперника. Используй % как базу
> решения, а «дуэль лжи» (психологию ставок) докручивай сам.

## Запуск на своём ПК

Приложение полностью автономное (нет внешних зависимостей, интернет не нужен).
Сначала забери папку `WeplayCard` целиком (или только нужные файлы) на свой компьютер:
через git (`git clone` репозитория) либо просто скопируй папку из этого рабочего пространства.

### Вариант А — один файл, без сервера (проще всего)
Возьми **`weplaycard-standalone.html`** — это весь проект в одном файле (стили и скрипты
внутри). Просто **двойной клик** по нему → откроется в браузере. Работает офлайн, можно
скинуть файл кому угодно.

### Вариант Б — локальный сервер (Python, есть почти везде)
В папке `WeplayCard` выполни:
```bash
python3 serve.py            # http://localhost:8000
python3 serve.py 8080       # или свой порт
```
Открой в браузере `http://localhost:8000`. Остановить — `Ctrl+C`.

### Вариант В — локальный сервер (Node.js, если нет Python)
```bash
node server.js              # http://localhost:8000
node server.js 8080         # или свой порт
```
Открой `http://localhost:8000`. Остановить — `Ctrl+C`.

### Windows — проще всего
Если у тебя Windows и есть GitHub Desktop: просто двойной клик по **`start.bat`** в папке
проекта. Он сам найдёт Python или Node, поднимет локальный сервер и откроет
`http://localhost:8000` в браузере. Если ни Python, ни Node не установлены — откроет
`weplaycard-standalone.html` напрямую (без сервера, офлайн).

> Сервер нужен, если хочешь открыть приложение с телефона в той же Wi-Fi-сети
> (введи `http://<IP-адрес-ПК>:8000`) или просто предпочитаешь запуск как веб-сайт.
> Для обычного использования на одном ПК достаточно Варианта А.

Модульная структура (`index.html` + `styles.css` + `engine.js` + `app.js`) нужна,
если захочешь дорабатывать код; собрать из неё одиночный файл можно скриптом
`node build-standalone.js` (он сгенерирует `weplaycard-standalone.html`).

## Как запустить (Telegram-бот, опционально)

Бот переиспользует тот же `engine.js`:

```bash
npm install node-telegram-bot-api
TELEGRAM_TOKEN=твой_токен node bot.js
```

Команды в чате:
```
/calc С9 К9 С5К2Ж7Ф3 2
```
Цвета: `С К Ж Ф`, значения `1-9`. Первые две карты — твои, дальше — общие, последнее число — число соперников.
